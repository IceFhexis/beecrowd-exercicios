# Resolução de exercícios do beecrowd

## Autor
Daniel José

Repositório com minhas resoluções dos exercícios utilizados nas aulas.

A ideia aqui é compartilhar como eu pensei em cada problema e algumas das soluções que encontrei. Não significa que sejam as únicas formas de resolver — provavelmente você vai encontrar caminhos diferentes (e talvez até melhores).

Em alguns exercícios também deixei soluções alternativas, seja para simplificar o código ou para experimentar outros recursos do Python.

Cada exercício possui um arquivo `ideia.md`, onde tento explicar o raciocínio e os passos que segui, e um `resposta.py` com a implementação.

O objetivo não é servir como gabarito, mas como material de apoio para quem quiser comparar ideias ou entender uma abordagem diferente.

## Como usar o repositório

Se estiver travado em algum exercício, uma sugestão:

1. Dê uma olhada no `ideia.md` e tente continuar a partir dali.
2. Monte a sua própria solução, mesmo que fique diferente da minha.
3. Depois, se quiser, veja o `resposta.py` para comparar as abordagens.

Se a sua solução chegou ao mesmo resultado de outra forma, ótimo. Parte da graça é justamente perceber que o mesmo problema pode ser resolvido de vários jeitos.
