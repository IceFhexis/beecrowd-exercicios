# 1142 - PUM

## Ideia
Cada linha usa tres numeros consecutivos e depois a palavra `PUM`. Como a proxima linha deve comecar quatro unidades depois, basta controlar o primeiro numero.

## Passos
1. Ler a quantidade de linhas `N`.
2. Comecar o primeiro numero em 1.
3. Para cada linha, imprimir `numero`, `numero + 1`, `numero + 2` e `PUM`.
4. Aumentar `numero` em 4.
