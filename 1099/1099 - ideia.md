# 1099 - Soma de Impares Consecutivos II

## Ideia
Para cada par, identificar o menor e o maior valor e somar apenas os numeros impares estritamente entre eles.

## Passos
1. Ler a quantidade de casos.
2. Ordenar cada par de limites.
3. Percorrer os valores entre os limites e acumular os impares.
4. Imprimir uma soma por linha.
