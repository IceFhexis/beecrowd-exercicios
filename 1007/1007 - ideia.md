# 1001 - Diferença

## Ideia
Ler quatro numeros inteiros, calcular a diferença do produto de A e B pelo produto de C e D.

## Passos
1. Ler `A`, `B`, `C`, `D`.
2. Calcular `(A * B - C * D)`.
3. Imprimir o valor.

## Pseudocodigo
```text
leia A, B, C, D
resultado <- (A * B - C * D)
mostre resultado
```
