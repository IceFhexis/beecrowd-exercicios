# 1079 - Medias Ponderadas

## Ideia
Cada caso possui tres notas com pesos 2, 3 e 5. A media ponderada e a soma dos produtos dividida pela soma dos pesos.

## Passos
1. Ler a quantidade de casos.
2. Ler tres notas para cada caso.
3. Calcular `(nota1 * 2 + nota2 * 3 + nota3 * 5) / 10`.
4. Imprimir o resultado com uma casa decimal.
