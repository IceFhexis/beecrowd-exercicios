# 1176 - Fibonacci em Vetor

## Ideia
Precalcular a sequencia de Fibonacci ate o maior indice permitido e consultar os valores pedidos.

## Passos
1. Criar os valores de Fibonacci de `Fib(0)` ate `Fib(50)`.
2. Ler a quantidade de casos.
3. Para cada caso, ler o indice e consultar o valor correspondente.
4. Imprimir no formato solicitado.
