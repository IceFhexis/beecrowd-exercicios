# 1959 - Polígonos Regulares Simples

## Ideia
Pegar a quantidade de lados do poligo, 
juntamente ao comprimento de cada um.

E retornar o perimetro do poligono

P = N * L

onde P é o perimetro
N é a quantidade de lados
e L é o comprimento de cada lado

## Passos
1. Ler o número inteiro N e L.
2. Calcular o perímetro.
3. Imprimir o perímetro.

## Pseudocodigo

```text
Ler N, L

P = N * L

Imprimir P
```
